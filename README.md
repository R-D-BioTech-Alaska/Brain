Brain has been combined with Qelm. Brains Quantum System wont be released, but its benchmarks, its knowledge files and information based knowledge will be available as time allows. Currently Brain is at 237x parameter advantage compared to regular llms at over 90% efficancy. 

## Projected Brain Model Efficiency

Brain is designed to target the practical capabilities of much larger conventional language models while using a significantly smaller active parameter footprint.

| Practical Capability Target | Conventional Model Size | Projected Brain Size |
| --------------------------- | ----------------------: | -------------------: |
| Large local model           |          70B parameters |     ~296M parameters |
| GPT-3-scale model           |         175B parameters |     ~739M parameters |
| Very large model            |         405B parameters |    ~1.71B parameters |
| Trillion-parameter system   |           1T parameters |    ~4.22B parameters |
